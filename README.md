## Что это

Обычные примеры дают копейки. Настоящие деньги приносят **узелки, счётные палочки и счёты** —
они сами решают примеры в фоне, пока ты отдываешь. Накопил 10 денег — иди на контрольную:
за неё дают награду и открывают **магазин контрольных улучшений**, где множители дохода,
более широкое окно скорости и новые математические действия.

## Как играть

Играть можно в браузере, на Windows или на Android:

**🌐 В браузере** — [konstantinkasatkin2-rgb.github.io/mathidle](https://konstantinkasatkin2-rgb.github.io/mathidle/)
Работает на компьютере и на телефоне, ничего устанавливать не нужно.
Вёрстка проверена на экранах от 320×568 до 1280×800: страница не
прокручивается, навигация закреплена снизу и всегда на виду.

**💾 Локально** — `bash tools/serve_web.sh`, затем открой <http://localhost:8765>.
Просто открыть `web/index.html` двойным щелчком нельзя: по `file://` браузер
не даёт доступ к `localStorage`, и прогресс не сохраняется.

**🖥 Windows** — `MathIdle.exe` из архива релиза.

**📱 Android** — `MathIdle.apk` из архива релиза.

Прогресс сохраняется отдельно в каждой версии, своими настройками и своим
`localStorage` — переносить его между ними не нужно.

### Аккаунт и хранение прогресса

По умолчанию прогресс лежит **на устройстве**. Если создать аккаунт, игра
дополнительно отправляет сохранение на сервер — и на другом устройстве можно
продолжить с того же места.

```bash
bash tools/serve_accounts.sh          # сервер аккаунтов на :8766
```

Дальше — вкладка **Настройки** в игре: «Регистрация» / «Войти». Пароли
хранятся в виде PBKDF2-хэша с солью, сервер не видит их в открытом виде.

#### Где лежат данные

Отдельный файл **`D:\mathidle\mathidle_accounts.db`** — и он **зашифрован**.
Это не SQLite, а контейнер: ChaCha20 + HMAC-SHA256. Имена игроков, хэши
паролей и сохранения прогресса в открытом виде на диске не лежат, открыть
базу текстовым редактором нельзя. Ключ — в `mathidle_accounts.db.key` рядом.

Честно о том, что это значит: ключ лежит на том же диске, поэтому шифрование
защищает от случайного подглядывания и от чужих программ, читающих файл, — но
не от того, кто забрал всю папку. Настоящая защита — вообще не хранить ключ:

```bash
set MATHIDLE_DB_KEY=пароль              # Windows
export MATHIDLE_DB_KEY=пароль           # Linux, macOS
bash tools/serve_accounts.sh
```

Тогда ключ выводится из пароля и на диске его нет. Обратная сторона:
забытый пароль означает потерю всех аккаунтов без возможности восстановления.

#### Телефон

Приложение на Android **находит сервер сам**: спрашивает по UDP, кто
отвечает в локальной сети, — так же, как телефон находит принтер. Ничего
вводить не нужно, только запусти сервер на компьютере, в той же сети, что и
телефон. Если широковещание в сети запрещено, адрес вводится руками в
настройках — это IP компьютера в сети, а не `127.0.0.1` (телефон иначе ищет
сервер у себя):

```
http://192.168.1.10:8766
```

Сервер по умолчанию слушает всю сеть (`0.0.0.0`), иначе телефон его не увидит.
Пароли хранятся хэшами, но прогресс и имена доступны любому в этой сети — для
одного компьютера запускай `bash tools/serve_accounts.sh 8766 127.0.0.1`.

#### Если игра открыта по HTTPS

Сайт на GitHub Pages открыт по HTTPS, а такая страница не может ходить на
http-сервер: браузер блокирует запрос, и игра показывает «Failed to fetch».
Тогда сервер поднимают по HTTPS, сертификат создаётся сам:

```bash
bash tools/serve_accounts.sh --https
```

Если адрес в сети не тот, что угадал скрипт, сертификат перевыпускается под
него — иначе браузер его отвергнет: `bash tools/make_cert.sh 192.168.1.10`.
Сертификат самоподписанный, поэтому браузер один раз спросит подтверждение —
нажми «Всё равно перейти». В приложении на Android подтверждения не будет,
поэтому там используется обычный http.

Сервер: `server/account_server.py` — только стандартная библиотека Python,
данные в SQLite (`server/mathidle.db`). Если сервер выключен, игра работает
как обычно, просто без синхронизации.

### Управление и что делать

| Действие | Что делать |
|---|---|
| Пример | Вводи ответ цифрами или экранными кнопками, `Enter` — проверить |
| Улучшения | Вкладка **Улучшения**: покупай узелки / палочки / счёты |
| Контрольная | Вкладка **Контрольная**: билет стоит 10 денег, ошибся — билет возвращают |
| Магазин | Открывается после первой сданной контрольной |

Управление: `Enter` — ответ, `Backspace` — стереть, `Delete` — очистить, `Tab` — вкладка,
`Esc` — сохранить и выйти.

## Правила начисления денег

```
деньги = потолок_действия × сложность × скорость × множители × серия
```

- **Потолок** — максимум за пример действия. Сложение по ТЗ даёт максимум **0.01**.
- **Сложность** — `1 − 0.65·d`, где `d` ∈ [0, 1] насколько пример трудный. Чем сложнее, тем меньше денег.
- **Скорость** — `1.0` за мгновенный ответ, плавно падает до `0.2` за долгий. «Скоростной бланк» расширяет окно.
- **Серия** — до +50% за несколько верных ответов подряд.

Пассивные примеры решаются **непрерывно во время игры**, а не только когда ты
в игре не находишься. В верхней панели видно, сколько накоплено за сессию, а в
вкладке «Улучшения» — тот же счётчик подробнее.

### Престиж и вознесение

**Престиж** доступен, когда решён пример сложности 100%. Он обнуляет деньги,
обычные и контрольные улучшения, но **открытые операции остаются** (вычитание,
деление и т.д.). Очки престижа начисляются по курсу **1 деньга = 0.01 очка**.

После первого престижа открывается магазин престижных улучшений и смешанные
примеры — с двумя и более разными действиями в одной строке.

**Вознесение** обычного улучшения доступно после первого престижа, когда
улучшение доведено до максимума: уровень сбрасывается на ноль, скорость
удваивается, а цена учетверяется. Повторять можно сколько угодно раз.

Самый дорогой престижный апгрейд — **Femboy Futa house** за 7.21 очка
(сейчас действует скидка 15%). Эффектов у него нет, зато после покупки
экран потемнеет.

### Проверки

| Вид | Билет | Темы | Награда |
|---|---|---|---|
| Контрольная | 10 | две **случайные** открытые операции | обычная |
| Итоговая контрольная | 150 | все открытые операции, чуть сложнее | ×4 |
| Экзамен | 1500 | все темы разом, самый сложный | ×12 |

Экзамен открывается после двух сданных контрольных.

### Базовые улучшения

| Улучшение | Скорость | Максимум | Стартовая цена | Рост цены |
|---|---|---|---|---|
| Узелки | +0.01 примера/с | 0.1 | 0.2 | `0.1 + 0.2(n−1)` |
| Счётные палочки | +0.03 примера/с | 0.3 | 0.6 | `0.3 + 0.6(n−1)` |
| Счёты | +0.05 примера/с | 0.5 | 0.5 | `0.5 + 0.5(n−1)` |

Цена n-й покупки — арифметическая прогрессия: `a1 + (n − 1)·d`.
Каждый улучшение прокачивается на 10 уровней: суммарно 0.9 примера в секунду,
67.5 денег на всё.

### Магазин контрольных улучшений

Открывается после первой сданной контрольной: множители денег («Двойная тетрадь»,
«Тетрадь в клетку»), ускорение («Скоростной бланк»), пассивный доход («Автоответчик»),
подсказки («Шпаргалка») и новые действия — вычитание, умножение, деление, порядок действий.

## Две версии игры

| | Windows | Android |
|---|---|---|
| Что это | pygame + PyInstaller (onedir) | HTML5/JS в нативном WebView |
| Файл | `MathIdle-windows.zip` (13 МБ) | `MathIdle.apk` (98 КБ) |
| Запуск | распакуй архив и запусти `MathIdle.exe` | установи APK |

Windows-сборка папочкой, а не одним `.exe`: onefile распаковывает DLL во временный
каталог в `%TEMP%`, и антивирус (в том числе Defender) периодически блокирует
свежие файлы — запуск падает с «Failed to load Python DLL». В папке распаковки
нет, поэтому `MathIdle.exe` запускается сразу.

Обе версии берут баланс из одного файла `mathidle/config.py`, который выгружается
в `web/balance.js`. Тест `tools/parity.py` сверяет **2436 значений** — если цифры
разойдутся, тест упадёт.

### Почему Android — это WebView, а не buildozer

Классический путь (buildozer / python-for-android) требует Linux, WSL или Docker
и прав администратора. На этой машине ничего из этого нет, поэтому Android-сборка —
это HTML5-игра в тонкой нативной обёртке без зависимостей (даже без AndroidX).
Приложение полностью офлайн, весит меньше 100 КБ и не просит никаких разрешений.

Детали в [`android/README.md`](android/README.md).

## Сборка

```bash
bash tools/fetch_toolchain.sh      # JDK 17 + Android SDK + Gradle + Node, без прав админа
bash tools/build_exe.sh            # dist/MathIdle/ + dist/MathIdle-windows.zip
bash tools/build_apk.sh            # dist/MathIdle.apk
bash tools/serve_accounts.sh       # сервер аккаунтов
```

`build_exe.sh` сам запускает собранный `MathIdle.exe --selftest` и печатает отчёт —
если сборка сломалась, скрипт это покажет.

## Проверки

```bash
bash tools/test_all.sh
```

| Проверка | Что делает |
|---|---|
| `tools/selftest.py` | генераторы, цены, награды, игровой цикл, сохранение |
| `tools/render_test.py` | рисует экраны в PNG, ищет недостающие глифы шрифта |
| `tools/parity.py` | сверяет Python и JS на 2891 значении |
| `tools/webtest.mjs` | 65 проверок HTML5-версии в jsdom (клики, клавиши, сохранения) |
| `tools/layout_check.sh` | раскладка в настоящем браузере на 6 размерах экрана: ничего не вылезает |
| `tools/account_check.sh` | регистрация, вход и ошибки сервера в настоящем браузере |
| `tools/mixedcontent_check.py` | воспроизводит блокировку запроса HTTPS-страницы на HTTP-сервер |
| `tools/make_cert.sh` | сертификат для HTTPS-сервера аккаунтов |
| `tools/crypto_test.py` | шифрование базы: ChaCha20 сверен с RFC 8439 и с openssl |
| `tools/store_test.py` | сервер, зашифрованная база, перезапуск, поиск в сети |
| `tools/push_via_api.py` | заливает коммит через API, когда `git push` падает у GitHub |
| `MathIdle.exe --selftest` | проверяет упакованный бинарник: ресурсы, ввод, игровой цикл, сохранения |

Сервер аккаунтов проверяется отдельно: `python server/account_server.py` и
`tools/selftest.py` (раздел «Аккаунты»).

Отчёт самопроверки в windowed-сборке (консоли нет) пишется в
`mathidle-selftest.txt` рядом с `.exe`.

## Структура

```
mathidle/           игра на pygame
  config.py           ВЕСЬ баланс в одном месте (правится только он)
  account.py          клиент сервера аккаунтов
  problems.py         генераторы примеров
  economy.py          цены, награды, форматирование
  state.py            состояние, контрольные, сохранения
  ui.py               отрисовка и ввод
  assets.py           шрифты и ресурсы
web/               HTML5-версия (index.html, game.js, style.css)
server/            сервер аккаунтов (Python + SQLite, без зависимостей)
android/           Gradle-проект с WebView-обёрткой
tools/             сборка, тесты, выгрузка баланса, иконки
```
